{{/* Every control below carries hx-preserve, which keeps the existing element instead of building a new one on each swap. The device pushes state about every two seconds and the whole player is replaced each time, so without this the buttons are destroyed and rebuilt roughly thirty times a minute — including the one under a finger. A tap leaves a button focused, the next swap throws that node away, and the pressed look drops off and comes back: on a tablet it reads as flickering. A song change makes it worse, since the device bursts several updates in quick succession. Preserving them is safe precisely because the markup is static: what changes is the values, and those are not inside a preserved element. */}}
